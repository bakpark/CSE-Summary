# kpap Playground 프로토타입

설정·실행·오프라인 평가·온라인 평가·처리 과정 조사를 체험한다.

- 브라우저에서 모의 데이터로 동작한다.
- 모델·A2A·Langfuse API는 연결하지 않았다.
- 변경은 브라우저에 저장한다. 데모 초기화로 복구한다.
- 실제 운영 설정·정책·고객 데이터는 변경하지 않는다.

[비공개 체험 링크](https://kpap-playground-prototype.justgecko33.chatgpt.site) · ChatGPT 로그인 필요.

## 실행

프로토타입 폴더에서 실행한다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:4173 을 연다.

## 확인 흐름

설정 저장 → 시험 실행 → 처리 과정 → 평가 비교 → 온라인 사례 → 데이터셋 반영.

실행 화면에서 정상·도구 오류·추가 입력·수집 지연·원격 결과 불명 상태를 선택한다.
