# kpap 오프라인 평가 규칙

[Playground 기획](07-playground-product-spec.md)의 실험·비교 보완 규칙이다.

## 실행 조건

실험은 코드·데이터셋·설정·평가기 버전을 고정한다. 항목·반복·시도·run을 연결한다. 정답은 업무 입력과 분리한다.

플랫폼 실행은 A2A를 호출한다. 로컬 실행은 Plugin 개발 worker가 SDK 핸들러를 실행한다. 결과 구조는 같다.

추가 입력이 필요한 자동 평가는 사전 대화 스크립트가 필요하다. 조건이 없으면 미지원으로 표시한다.

## 진행과 비교

- 업무 실행과 평가 진행을 구분한다.
- 완료 항목은 실험 종료 전에 조사할 수 있다.
- 중단은 신규 배정을 멈추고 진행 작업 취소를 요청한다.
- 실패 항목 재실행은 새 실험으로 남긴다.
- 같은 입력 hash·반복·평가 기준의 쌍만 비교한다.
- 비교 불가·평가 실패·제외 수를 표시한다.
- 업무 trace와 judge trace를 분리한다.

## 집계

| 지표 | 기준 |
|---|---|
| 실행 성공률 | 최종 성공 항목 반복 수 / 배정 항목 반복 수 |
| 평가 커버리지 | 유효 평가 수 / 평가 대상 수 |
| 통과율 | 통과 수 / 유효 판정 수 |
| 평균 점수 | 같은 평가기·척도의 유효 점수 |
| 회귀율 | 기준 이상 하락한 쌍 / 유효 비교 쌍 |
| 지연·비용 | 업무·평가 분리. 미상·표본 수 표시 |

재시도·취소·미시작·조건 미충족 제외는 별도로 집계한다. 여러 평가기 점수를 자동 합산하지 않는다. 선택 항목 개선을 전체 품질 개선으로 표시하지 않는다.

완료 기준은 고정 조건 비교, 회귀 근거 조사, 전체 데이터셋 재검증이다.
