# Playground 디자인 규칙

v21 / 2026-10-24. 기존 작업공간과 분할 패널 구조를 유지한다. 이 문서는 표시 규칙이며 API·상태·실행 계약을 변경하지 않는다.

## 색상과 상태

- 색상 값은 `dist/palette.css`에서만 정의한다. 컴포넌트는 토큰을 참조한다.
- 기본 화면은 중립 회색을 사용한다. 주요 액션·키보드 포커스·명시적 전이 입자에만 강조색을 사용한다.
- 오류·경고 색은 실제 상태의 텍스트·아이콘에만 사용한다. 패널 전체를 물들이지 않는다.
- 선택 상태는 중립 배경과 완전한 외곽선으로 표시한다. 장식용 왼쪽 막대와 그림자는 사용하지 않는다.
- 키보드 포커스는 선택 상태에서도 2px 강조색 외곽선으로 표시한다.
- 과거 활성 구간은 중립 외곽선과 구간 문구로 표시한다. 불확실한 구간은 점선과 설명으로 구분한다.
- 실행 전이 애니메이션은 명시적 predecessor 정보와 일치하는 설계 간선에만 적용한다.
- reduced-motion에서는 장식 효과를 제거한다. 수동 탐색과 기록 재생 기능은 유지한다.

## 컴포넌트

- 한국어 sans-serif를 사용한다. 본문은 12–13px, 보조 정보는 11px, 절 제목은 15px를 기준으로 한다.
- 코드는 실제 코드·식별자에만 monospace를 사용한다.
- 간격은 4px 리듬을 따른다. 컨트롤·패널의 모서리와 경계선을 일관되게 유지한다.
- 트리·타임라인·로그·필터·점수·메타데이터·근거·재생·평가 기능은 스타일 변경으로 숨기지 않는다.

## 참고와 검증

[Impeccable](https://github.com/pbakaus/impeccable)의 Operate·quieter·distill 방향과 [anti-slop 예시](https://impeccable.style/slop/)를 디자인 참고로 사용했다. 이전 검토에는 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)을 참고했다. 외부 도구 설치나 자동 디자인 인증을 의미하지 않는다. 외부 가이드 원문은 이 폴더에 복제하지 않았다.

`tests/palette.test.cjs`는 중앙 팔레트·컴포넌트의 색상 토큰·대비·왼쪽 장식선 제거를 검사한다. `tests/component-system.test.cjs`는 기능 노출·포커스·표시 계약을 검사한다. 소스 검사는 실제 브라우저·모바일 접근성 검증을 대체하지 않는다.
