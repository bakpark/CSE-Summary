## 시나리오 A 노드 설정을 바꿔 시험

목표: 수정한 설정이 응답과 수행 경로에 미친 영향을 확인한다.

| 액션 | 화면 | 화면 변화·다음 행동 |
|---|---|---|
| 실행 선택 | S01 | 현재 초안과 입력 복원 |
| 그래프 노드 선택 | S01 | 해당 노드의 지원 설정만 표시 |
| 모델·본문·지식·도구 변경 | S01 | 변경 노드 표시. 다른 노드의 초안 유지 |
| 입력 작성 후 실행 | S02 | 설정 고정·노드 진행·조건에 따른 분기 표시 |
| 결과 확인 | S02 | 최종 응답·수행/생략 경로 확인 |
| 관측 선택 | S06 | 해당 run과 노드의 관측 상세로 이동 |

설정 오류는 해당 필드에 표시한다. 현재 실행 중 편집한 값은 다음 실행에 적용한다.

## 시나리오 B 이력을 확인하고 재사용

목표: 초안을 잃지 않고 과거 설정·결과를 조사한다.

| 액션 | 화면 | 화면 변화·다음 행동 |
|---|---|---|
| 이력 열기 | S03 | 같은 화면 오른쪽에 목록 표시 |
| 과거 실행 선택 | S03 | 과거 설정·결과를 읽기 전용으로 표시 |
| 편집으로 복귀 | S01 | 기존 초안·선택 노드·입력 복원 |
| 가져오기 | S01 | 과거 설정을 새 초안으로 복사 |
| 기준 지정 | S03 | 다음 비교의 기준 고정 |

조회와 가져오기를 구분한다. 이력을 닫아도 초안을 유지한다.

## 시나리오 C 후보를 오프라인 평가

목표: 같은 평가 조건에서 개선·회귀를 확인한다.

| 액션 | 화면 | 화면 변화·다음 행동 |
|---|---|---|
| 평가 선택 | S04 | 노드 초안 유지. 입력 영역을 데이터셋·평가기로 전환 |
| 데이터·평가 기준 선택 후 평가 | S04 | 코드·노드·설정·데이터·평가기 버전 고정 |
| 항목 선택 | S04 | 해당 응답·근거·실제 수행 경로 표시 |
| 이력에서 기준 지정 후 비교 | S05 | 노드 설정 차이와 유효 점수 차이 표시 |
| 관측 보기 | S06 | 선택 실험·항목·업무 관측 연결 |
| 평가기 선택 | S08 | 점수 생성 또는 실패한 judge 호출 표시 |

평가 오류는 0점과 구분한다. 조건이 다른 결과는 직접 비교하지 않는다. 수정 후 평가는 새 실험으로 기록한다.

## 시나리오 D Langfuse 방식으로 원인 조사

목표: 업무 호출과 평가 호출을 구분하여 지연·출력·점수의 근거를 찾는다.

| 액션 | 화면 | 화면 변화·다음 행동 |
|---|---|---|
| 추적 선택 또는 결과의 관측 클릭 | S06 | 같은 실행 문맥으로 Trace 상세 표시 |
| 실행·평가 항목 선택 | S06 | 해당 관측 트리·요약 로딩 |
| 관측 검색 | S06 | 이름·ID·종류로 호출 목록 필터 |
| 루트/호출 선택 | S06 | 해당 모델·기간·사용량·입출력 표시 |
| Timeline 선택 | S07 | 같은 관측을 시간축으로 표시 |
| 타임라인 호출 선택 | S07 | 동일 관측 상세 선택 |
| 메타데이터/점수 선택 | S06 | 실행·설정 연결 정보 또는 평가 결과 표시 |
| 업무/평가기 전환 | S06/S08 | 서로 다른 호출·비용·오류 조사 |
| 실행 또는 평가로 복귀 | S01/S04 | 편집 초안 유지 |

생략·미계측·수집 중·조회 오류를 구분한다. 실제 서비스에서는 권한·마스킹 정책을 적용한다.

## Langfuse 화면 구성 기준

Trace 요약 아래에 호출 계층과 관측 상세를 둔다. Tree/Timeline은 같은 관측을 표현한다. 상세는 입출력·메타데이터·점수로 구분한다. 검색과 관측 선택은 양쪽 뷰에서 유지한다.

Langfuse가 2025년에 발표한 계층·Tree/Timeline·검색·입출력 구조를 참고한다. 배포된 v3 화면의 모든 기능을 복제하는 것은 아니다. [공식 Trace View 안내](https://langfuse.com/changelog/2025-03-19-new-trace-view)

## 완료 기준

액션마다 대상 실행·선택 노드·초안·평가 조건을 보존한다. 이력 조회가 초안을 덮어쓰지 않아야 한다. Tree와 Timeline이 같은 관측 상세를 열어야 한다. 평가기 오류가 업무 실패나 낮은 점수로 표시되지 않아야 한다.
