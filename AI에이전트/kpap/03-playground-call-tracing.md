# kpap 호출과 트레이싱 규칙

[Playground 기획](07-playground-product-spec.md)의 호출·관측 보완 규칙이다.

| 상황 | 처리 |
|---|---|
| 설정 검증 | 미지원·권한·변수 오류를 실행 전에 반환 |
| 실행 | 요청·해석·적용 설정을 연결 |
| 즉시 응답·task | 같은 실행 화면에서 처리 |
| 추가 입력 | 같은 run·task·스냅샷 유지 |
| 취소 | 접수와 완료 구분 |
| 스트림 단절 | 같은 실행 재연결. 자동 재실행 없음 |
| 원격 결과 불명 | unknown 표시·상태 조회 |
| 관측 지연 | 업무 결과 유지·수집 상태 표시 |
| 부분 관측 | 도착 구간 표시·누락 범위 안내 |
| 다시 실행 | 확정 버전 재사용과 현재 참조 재해석 구분 |

관측 상세는 모델·프롬프트·도구·검색 출처·오류·재시도를 연결한다. 병렬 구간의 시간을 전체 지연으로 합산하지 않는다. 비용 0과 미상을 구분한다.

업무 결과·수집 상태는 [공통 규격](00-common-contracts.md)을 따른다. 조회·권한·원문 처리는 [Langfuse 연동](08-langfuse-v3-integration.md)을 따른다.

완료 기준은 결과에서 실제 설정과 실패 구간을 찾을 수 있는 것이다.
