# Agent Playground 성과 지표 측정 기준

> 작성일: 2026-10-07. 상태: 합의 지표의 측정 정의.
> 기준: [상위 기획의 성과 확인 지표](./agent-playground-draft.md#6-성과-확인-지표).

## 1. 합의 지표

| 지표 | 측정 정의 | 기준값 수집 |
| --- | --- | --- |
| 에이전트 개선·평가 주기 소요 시간 | 개선 작업 시작부터 수정·재평가를 거쳐 평가 결과 검토를 마칠 때까지의 경과 시간 | Phase0 |
| 에이전트 수정 후 품질 검증 소요 시간 | 수정본 제출부터 정해진 품질 기준의 통과 여부를 확인할 때까지의 경과 시간. 패키지 준비·실행·평가 대기를 포함한다. | Phase0 |
| 실험 변경 제안 검토 완료율 | 검토 기간이 지난 제안 중, 해당 기간 안에 개발자가 검토하고 반영 여부를 결정한 제안의 비율 | Phase1 |

개선·평가 주기 시간은 협업 전체의 결과 지표다. 품질 검증 시간은 그 안의 병목을 확인하는 하위 지표다. 두 시간을 더하거나 독립 성과로 합산하지 않는다. 품질 검증은 기준을 달성할 때까지의 시간이 아니라, 제출한 수정본의 통과 여부를 확인하는 시간이다.

## 2. 시간 측정 기준

- 개선 작업과 수정본에 ID를 부여한다. 개선 시작·수정본 제출·통과 여부 확인·결과 검토 완료 시각을 기록한다.
- 한 개선 주기에서 여러 수정본을 제출하면, 수정본별 검증 시간을 기록한다. 개선 주기는 결과 검토를 마칠 때 종료한다.
- 기존 방식과 유사한 개선 과제로 비교한다. 테스트 셋·평가 범위·품질 기준을 유지한다. 적용한 기준과 정확한 형상을 기록한다.
- 완료 건의 시간과 실패·시간 초과·미완료 상태를 함께 확인한다. 실행 실패는 품질 기준 미충족 판정과 구분한다.

## 3. 제안 검토 완료율

기획자가 공유한 플로우·설정 변경 제안에 ID와 최초 공유 시각을 기록한다. 검토 기간은 제안 공유 전에 정한다. 공유 후에는 해당 제안의 검토 기간을 바꾸지 않는다.

- **분모:** 집계 시점까지 검토 기간이 지난 제안 수.
- **분자:** 분모에 포함된 제안 중, 정해진 기간 안에 개발자 검토와 반영 여부 결정이 완료된 수.
- 반영·부분 반영·미반영은 결정 이유를 기록하면 완료로 처리한다. 보류는 미완료다.
- 검토 기간이 아직 지나지 않은 제안은 별도로 조회한다. 기간 이후에 완료한 제안은 기한 내 완료로 계산하지 않는다.
- 집계 시점·검토 기간·분자·분모를 함께 표시한다. 이 비율은 제안이 방치되지 않고 기한 내 검토되는지 확인한다. 반영·부분 반영·미반영의 결정 유형과 이유도 함께 읽는다.

## 4. 기록과 적용

개선 작업 기록과 Runner·평가 기록에서 시간을 확인한다. Playground·plugin의 제안 기록에서 공유 시각·결정 시각·결정 이유를 확인한다.

Phase0에서 두 시간 지표의 기준값을 수집한다. Phase1에서 제안 검토 완료율의 기준값을 수집한다. 수치 목표는 파일럿 기준값을 확인한 뒤 정한다.
