# Agentic Work Platform의 정의

> **Agentic Work Platform은 조직의 일하는 방식을 에이전트로 담아내고, 사용자가 어떤 채널에 있든 안전하게 호출하고 실행할 수 있도록 제공하는 AI 업무 실행 기반이다.**

에이전트는 사용자에게 보이는 표면이다. 그 안에는 단순한 Prompt가 아니라 업무의 목표, 절차, 판단 기준, 사용할 도구, 사람의 승인 조건과 결과 형식이 함께 담긴다. 즉 에이전트를 만든다는 것은 하나의 챗봇을 만드는 것이 아니라, **반복 가능한 업무 방식과 Workflow를 실행 가능한 형태로 만드는 것**이다.

이렇게 만들어진 에이전트는 특정 Builder나 웹 화면에 종속되지 않는다. 동일한 에이전트를 Web, Slack, Claude Desktop 등 사용자가 실제로 일하는 여러 환경에서 호출할 수 있어야 한다. 초기에는 Claude Desktop을 첫 번째 사용 환경으로 삼고, 이후 Web과 Slack 등으로 공급 채널을 확장한다.

```text
조직의 업무 방식
      ↓
검증된 업무 에이전트
      ↓
Agentic Work Platform
  ├─ Claude Desktop
  ├─ Web
  ├─ Slack
  └─ API·Workflow
```

기존 웹 기반 Agent Builder는 빠르게 에이전트를 만들고 사용하는 데 유용하지만, 사용 환경이 해당 웹 서비스 안으로 제한될 수 있다. Agentic Work Platform은 에이전트의 정의와 실행을 사용자 화면에서 분리함으로써, 한 번 만든 에이전트를 여러 채널에 일관된 형태로 공급한다. Lobby와 같은 Builder, n8n과 같은 Workflow 도구, CCAB와 같은 코드형 Builder를 대체하기보다, 이들이 만든 업무 실행체가 다양한 채널에서 재사용될 수 있는 공통 기반을 제공한다.

또한 채널이 늘어나더라도 에이전트가 임의로 회사 시스템을 사용하게 해서는 안 된다. 플랫폼은 사용자와 에이전트의 신원을 구분하고, 허용된 도구와 데이터 범위, 실행 한도, 사람의 승인 조건을 일관되게 적용한다. 모든 실행은 기록되며 필요하면 즉시 중지하거나 권한을 회수할 수 있어야 한다.

따라서 Agentic Work Platform의 핵심 가치는 다음 세 가지다.

- **업무의 자산화**: 개인의 일하는 방식과 Workflow를 반복 가능한 에이전트로 만든다.
- **채널 독립적 공급**: 하나의 에이전트를 Claude Desktop, Web, Slack 등 다양한 업무 환경에서 사용한다.
- **안전한 실행과 권한 관리**: 어디서 호출되더라도 동일한 권한·승인·감사 기준 아래 실행한다.

6주 파일럿은 이 비전을 위한 첫 번째 초석이다. CCAB로 만든 에이전트를 안전하게 실행·검증하고, 라이프사이클과 Tool 권한을 적용한 뒤 Claude Desktop에서 사용할 수 있게 한다. 이후 동일한 에이전트를 Web과 Slack으로 확장함으로써, **사용자가 플랫폼을 찾아가는 것이 아니라 에이전트가 사용자가 일하는 채널로 찾아가는 환경**을 지향한다.
